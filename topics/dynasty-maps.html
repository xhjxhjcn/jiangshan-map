四、历代王朝与地图上常见的几个问题

1. 「王朝地图」和「朝代地图」是同一回事吗？

是。中文里「王朝」与「朝代」在讲中国历史地图时基本通用：王朝指由某一姓家族建立的统治政权 （如刘氏汉朝、李氏唐朝），朝代是史学分期习惯的叫法。本站的王朝地图按 战国 → 秦 → 西汉 → 东汉 → 三国 → 西晋 → 东晋十六国 → 南北朝 → 隋 → 唐 → 五代十国 → 北宋 → 南宋 → 元 → 明 → 清 → 民国 → 中华人民共和国 共 18 段排列。

2. 为什么有的王朝地图分很多阶段？

一个大王朝的版图并非一成不变。以唐为例，初唐、盛唐、安史之乱后、晚唐的疆域差别极大： 安西与北庭都护府在盛唐时远及中亚，而 755 年之后河西、陇右与西域先后陷于吐蕃。 因此本站为同一王朝保存了多个版图快照（例如唐收录 29 幅），拖动时间轴时会按年份自动切换， 比只看一张「最大疆域图」更接近史实。

3. 王朝地图上的边界是精确国界吗？

不是。古代疆域多为羁縻、藩属与军事控制线，缺乏现代意义的精确国界。本站的疆域与政区为 示意性近似，用于呈现大势与沿革关系，不作为边界依据。

4. 古今地名怎么对照？

每个王朝页都附有城池的古今地名对照表（如唐代「江州」对应今江西九江）。也可以直接进入 交互式地图，点击任意古城查看其「点地溯源」面板——同一地点在历代所属的 政权、政区与名称变迁会按时间列出来。
